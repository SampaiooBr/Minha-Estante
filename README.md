# 🏛️ Minha Estante

O **Minha Estante** é um aplicativo web interativo de catálogo e gerenciamento de mídias físicas (jogos de consoles e filmes em Blu-ray/DVD). Ele permite organizar sua coleção pessoal com capas, anos de lançamento, sinopses e ferramentas automatizadas de escaneamento de códigos de barras.

## ✨ Principais Funcionalidades

* **📚 Categorização por Mídias:** Abas dedicadas e organizadas para coleções de PS5, PS4, PS2, Blu-ray e DVD com proporções visuais padronizadas.
* **📸 Escaneamento de Código de Barrametos:** Leitor integrado de códigos de barras via câmera (QuaggaJS) para cadastro rápido de novos títulos.
* **⚡ Importação em Massa e Atualização Inteligente:** Ferramentas para adicionar múltiplos títulos simultaneamente por listas de texto e atualização automática de sinopses e metadados.
* **💾 Backup e Restauração (IndexedDB / JSON):** Exportação e importação completa de backups do catálogo em formato JSON para segurança dos dados locais.
* **💖 Apoio / PIX:** Botão integrado com modal interativo e cópia rápida de chave PIX do Nubank para apoiar o desenvolvimento do projeto.

---
*Desenvolvido para entusiastas e colecionadores que desejam preservar e gerenciar suas mídias físicas com elegância e praticidade.*
